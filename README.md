# 📊 Superstore Sales Analysis

An end-to-end Data Analytics project that analyzes Superstore sales data using **Python**, **MySQL**, and **Power BI**. The project demonstrates the complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL querying, business insights, and interactive dashboard creation.

---

## 📌 Project Overview

This project aims to analyze sales performance and identify key business insights from the Superstore dataset.

The analysis focuses on:

- Sales trends over time
- Regional sales performance
- Product and category analysis
- Customer behavior
- Shipping mode analysis
- Interactive business dashboard

# 🚀 How to Run

### Python

```bash
pip install -r requirements.txt
```

Run any Python script:

```bash
python Python/01_data_cleaning.py
```

---

### SQL

1. Import `cleaned_superstore.csv` into MySQL.
2. Execute SQL scripts in the following order:

- 01_basic_queries.sql
- 02_intermediate_queries.sql
- 03_advanced_queries.sql
- 04_analysis.sql

---

### Power BI

Open:

```
PowerBI/Superstore_Dashboard.pbix
```

Interact with the dashboard using the available slicers.
